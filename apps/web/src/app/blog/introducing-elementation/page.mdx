# Introducing Elementation

AI coding agents can write code quickly, but they still need clear context. A prompt like "fix the blue button" often sends them to the wrong file.

Elementation gives them the missing context. Open your app, click the exact element, write the feedback, and copy a prompt with the selector, computed styles, page context, and source location.

## The workflow

1. Click **Inspect** and select an element.
2. Write feedback like "make this smaller and use the brand color."
3. Copy the generated prompt into Codex, Cursor, or Claude Code.

## Try it now

The [playground](/playground) has the overlay live on a sample UI. When you are ready, [add the SDK](/docs/installation) to your own app.
