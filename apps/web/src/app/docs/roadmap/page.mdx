# Roadmap

Elementation's MVP focuses on the capture → prompt → copy loop, with a full integration
surface for AI agents on top. Here's what's shipped and what's next.

## Shipped

- **REST API** — a versioned `/api/v1` for sessions, annotations, events, and webhooks. See
  [REST API](/docs/rest-api).
- **MCP server** — agents read and resolve annotations directly, no copy-paste, via
  `npx elementation`. See [MCP server](/docs/mcp).
- **Webhooks** — signed event delivery with automatic retries. See
  [Webhooks](/docs/webhooks).

## Near term

- **Babel/SWC/Vite plugin** — inject `data-elementation-*` source attributes automatically
  at build time, so file/line resolution works everywhere with zero manual annotation.
- **Authentication and API keys** — project-scoped bearer tokens across the API and MCP
  (the MCP client already accepts a `--token`).

## Later

- **Team workspaces** — shared projects with roles.
- **Screenshot capture** — attach a cropped screenshot to each annotation.
- **Figma integration** — reference a design alongside the live element.
- **GitHub issue creation** — open an issue straight from an annotation.
- **First-class agent integrations** — deeper Cursor / Codex / Claude Code support.
- **Browser extension** — inspect any site without installing the SDK.

Have a request? Open an issue on [GitHub](https://github.com/elementation/elementation).
