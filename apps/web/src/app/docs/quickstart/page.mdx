# Quickstart

Generate your first Elementation prompt in a few minutes.

## 1. Create a project

Open the [dashboard](/dashboard), click **Create Project**, and copy the project key.

## 2. Install the overlay

Add `@elementation/sdk` and render `<ElementationOverlay />` in development. You can also skip setup and use the [playground](/playground).

## 3. Click Inspect

Run your app and click the Inspect icon in the bottom-right corner. Your cursor becomes an element picker.

## 4. Select an element

Hover over the page to see names highlighted. Click the exact element you want changed.

## 5. Add feedback

Write a short instruction:

> Make this button smaller and use the primary brand color.

## 6. Copy the prompt

Click **Add**, then copy the formatted Markdown and paste it into your AI coding agent.
